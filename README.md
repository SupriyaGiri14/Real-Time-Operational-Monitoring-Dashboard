# Real-Time-Operational-Monitoring-Dashboard
The Logistic Delivery Data Analysis project analyzed shipment and sales data (Jan 2022–Dec 2024) to evaluate delivery performance, revenue trends, and operational efficiency. Insights were presented through an interactive Power BI dashboard for real-time visualization and data-driven decision-making.

# technologies used
* Power BI: Data Cleaning and Real-time dashboard development.
* Cloud Platforms: Power BI Services.
